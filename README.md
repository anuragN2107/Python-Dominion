## 📚 Syllabus & Curriculum Overview

The repository is neatly cataloged into progressive chapters and hands-on projects designed for deep mastery[cite: 1]:

| Chapter / Folder | Core Topics & Focus Areas |
| :--- | :--- |
| **📁 Ch.-01_Introduction_to_Python**[cite: 1] | Python installation, environment setup, syntax basics, and writing your first scripts. |
| **📁 Ch.-02_Python_Variables,Datatypes & Operators**[cite: 1] | Variable assignment, core data types, type casting, arithmetic, logical, and bitwise operators. |
| **📁 Ch.-03_Strings**[cite: 1] | String indexing, slicing, built-in string methods, formatting, and escape sequences. |
| **📁 Ch.-04_Lists & Tuples**[cite: 1] | Mutable vs immutable collections, list comprehension, methods, and tuple packing/unpacking. |
| **📁 Ch.-05_Dictionary & Sets**[cite: 1] | Key-value pairs, dictionary methods, set theory operations, and hash-based lookups. |
| **📁 Ch.-06_Conditional_Expressions**[cite: 1] | Decision making with `if`, `elif`, `else` statements, and nested conditionals. |
| **📁 Ch.-07_Loops**[cite: 1] | Iteration using `for` and `while` loops, `break`, `continue`, `pass`, and loop else blocks. |
| **📁 Ch.-08_Functions**[cite: 1] | Function definition, arguments (`*args`, `**kwargs`), return values, recursion, and lambda functions. |
| **📁 Ch.-09_Project-1**[cite: 1] | **Milestone Project 1:** Practical application of core fundamentals and logic building. |
| **📁 Ch.-10_File_Handling**[cite: 1] | Reading, writing, and appending text/binary files with context managers (`with` statement). |
| **📁 Ch.-11_Exception_Handling**[cite: 1] | Error management using `try`, `except`, `else`, `finally`, and raising custom exceptions. |
| **📁 Ch.-12_Object_Oriented_Programming**[cite: 1] | Classes, objects, inheritance, polymorphism, encapsulation, and magic/dunder methods. |
| **📁 Ch.-13_Project-2**[cite: 1] | **Milestone Project 2:** Advanced script development combining file I/O, OOP, and error handling. |
| **📁 Ch.-14_Advanced_Python-1**[cite: 1] | Iterators, generators, decorators, and advanced functional constructs. |
| **📁 Ch.-15_Advanced_Python-2**[cite: 1] | Concurrency, advanced libraries, and high-performance coding techniques. |
